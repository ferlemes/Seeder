Seeder 2.2.0-offline for LilyGO T-Display-S3
Upstream commit: ba6e9ebe226222cbb04415a635a934eeae372dab
Target: tdisplay-s3-offline; ESP32-S3 revision 0.2; 16 MB flash.

Same radio-exclusion policy as the classic ESP32 build. ESP32_NO_BLOBS is
specific to the classic ESP32, so the S3 uses CONFIG_SEEDER_NO_RADIO and the
explicit minimal Wi-Fi/PHY components generated by prepare.py. They provide
headers and unused exclusion markers, not replacement radio API stubs.
No Wi-Fi, Bluetooth or coexistence is enabled. No proprietary radio libraries
are linked. A future call to an excluded radio API fails to link.

The Arduino core and bootloader are rebuilt from source. Arduino network
libraries are excluded. USB application CDC auto-start and both SDK consoles
are disabled. USB Serial/JTAG ROM download remains enabled for recovery.
One factory app, no OTA partition. No Secure Boot, flash encryption or eFuse
provisioning. No PSRAM dependency; 8 MB embedded PSRAM remains unused.
Upstream S3 display/button configuration is enabled (GPIO15 peripheral power,
ST7789 320x170 parallel bus, buttons on GPIO14/GPIO0).
Seed generation, coin/dice handling and uBitcoin sources are unchanged.

Tool versions: PlatformIO 6.2.0, espressif32 6.9.0, ESP-IDF 4.4.7
(3.40407.240606), Arduino 2.0.17 (3.20017.241212+sha.dcc1105b),
Xtensa ESP32-S3 GCC 8.4.0+2021r2-patch5.

Build in an isolated package cache, since prepare.py changes SDK build files:
  PLATFORMIO_CORE_DIR="$PWD/.platformio-offline" pio run -e tdisplay-s3-offline
If prepare.py changes, first run the same command with '-t clean'.
Audit (requires pyelftools):
  python hardening/audit.py "$PWD/.platformio-offline/packages/toolchain-xtensa-esp32s3/bin" tdisplay-s3-offline

S3 offsets: bootloader 0x0, partition table 0x8000, application 0x10000.
The merged image uses DIO, 80 MHz and 16 MB, and is flashed at offset 0.
The input images match the audited ELF sections. ROM radio address symbols
in the ELF do not represent emitted radio function bodies.
Static inspection is not an exhaustive proof or a physical RF measurement.
